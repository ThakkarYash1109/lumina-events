Lean Canvas & Business Model Specification

Structured startup formulation based on Indian Wedding & Event Market (TAM ₹5.5 Lakh Crore).

1. Problem

  • 68% of event hosts overpay due to opaque, fragmented pricing.
  • Hosts waste 2–3 weeks hunting and coordinating vendors.
  • Vendors lose 40% of potential bookings due to lack of digital visibility.
  • Lead-gen sites (JustDial/Sulekha) offer no payment escrow, leading to last-minute vendor ghosting.

2. Customer Segments

  • Event Hosts: Wedding planners, families, corporate coordinators (22-55 yrs, ₹50k - ₹50L budget).
  • Service Vendors: Caterers, florists, photographers, AV/light teams across Ahmedabad, Surat, and Tier 1/2 cities.

3. Unique Value Proposition

  • For Hosts: Transparent upfront pricing, vetted luxury portfolios, 100% money-back escrow protection.
  • For Vendors: Direct booking pipeline, zero middleman extortion, guaranteed payouts upon milestone delivery.

4. Solution & Unfair Advantage

  • Unified end-to-end booking completed in under 5 minutes.
  • Curated luxury brand reputation and invitation-only vendor onboarding.
  • Proprietary automated escrow contract and milestone release engine.

5. Revenue Streams

  • Platform Spread (Day 1): ~10% transaction commission (Vendor receives ₹9,000, Lumina adds ₹1,000, Host pays ₹11,000).
  • Premium Tier (Month 2+): ₹2,999/mo featured listing & analytics.
  • Lumina Guarantee (Month 6+): 2% escrow insurance warranty.

6. DPIIT & Compliance Readiness

  • Eligible for Startup India DPIIT recognition (Entity age < 10 years, turnover < ₹100 Cr).
  • Section 80-IAC 3-year tax exemption roadmap.
  • Digital Personal Data Protection (DPDP) Act 2023 compliance with explicit consent and zero dark patterns.

Java Programming Architecture & OOP Design

Implementation of enterprise Java 21 Object-Oriented Principles, Multithreading, and Custom Exceptions.

OOP Design Principles

  • Encapsulation: Private members, strict accessor validation across User, Booking, and Payment models.
  • Inheritance & Polymorphism: Abstract User class subclassed into HostUser and VendorUser overriding getRoleDescription().
  • Interface Segregation: Distinct contracts for MarketplaceService and PaymentService.

Custom Exception Handling

  • VendorNotFoundException: Thrown when an invalid partner ID is accessed.
  • BookingConflictException: Prevents double-booking a vendor on identical dates.
  • InvalidBookingException: Enforces boundary rules on guest counts and past dates.
  • PaymentFailedException: Guards escrow state transitions and sandbox declines.

Multithreading Concurrency

  • NotificationDispatcher: Asynchronous background worker pool decoupled from REST threads.
  • Utilizes LinkedBlockingQueue<NotificationTask> and Executors.newFixedThreadPool(2).
  • Dispatches confirmation alerts and vendor push updates with zero API latency.

File Management & Persistence

  • FileDataManager: Implements singleton pattern for file-based state serialization.
  • Saves and loads marketplace state directly to lumina_marketplace_data.json.
  • Enables persistent state between server restarts without requiring complex SQL installations.

E-Commerce Marketplace Flow & Escrow Security

Slide 11 Commission Engine and ethical e-commerce architecture.

The 10% Spread Model

  • Vendor quotes base service fee (e.g. ₹1,00,000 for luxury catering).
  • Lumina adds 10% platform spread (₹10,000) for security, vetting, and warranty.
  • Host pays total ₹1,10,000 into secure escrow sandbox.
  • Vendor receives guaranteed payout of ₹1,00,000 upon confirmed event completion.

Anti-Fraud & Fake Review Prevention

  • Cryptographic Booking Linkage: Reviews can only be submitted against a verified bookingId.
  • Unverified submissions are rejected or flagged with verifiedStayOrBooking = false.
  • Prevents competitor smear campaigns and synthetic paid ratings.

Ethical UI & Anti-Dark Patterns

  • Zero Drip Pricing: What the host sees on the card is the final price including all taxes and fees.
  • No Pre-Checked Addons: Additional protection packages require deliberate user opt-in.
  • Clear Cancellation Rules: Escrow refund rules are displayed upfront before booking confirmation.

Software Testing Strategy & Quality Assurance

Complete test life-cycle covering black-box and white-box test design.

Boundary Value Analysis (BVA)

  • Invalid date partitions (Past dates rejected via InvalidBookingException).

Cloud Architecture & Cost Modeling

Public Cloud deployment blueprints (AWS / Azure / GCP) with Docker containerization.

Cloud Component Architecture

  • Frontend Layer: Static assets hosted on AWS S3 / Cloudflare Pages behind global CDN.
  • API & Backend Layer: Containerized Java 21 microservice running on AWS ECS / Google Cloud Run.
  • Database: Managed PostgreSQL (AWS RDS / Neon) with point-in-time recovery.
  • Object Storage: AWS S3 bucket for vendor portfolio images and automated nightly state backups.

Security & IAM

  • Enforced HTTPS/TLS 1.3 with automated Let's Encrypt certificates.
  • Environment variables managed via AWS Secrets Manager (zero hardcoded secrets).
  • Role-Based Access Control (RBAC) separating Host, Vendor, and Admin permissions.
